# Hanntec Engineering website (draft 2)

Plain HTML, CSS and a little JavaScript. No build step, no framework, and it can be hosted anywhere.
Open `index.html` in a browser to view it. If fonts look plain when opened by double-click, view it through any simple web server instead.

An earlier one-page draft is in `..\hanntec-website`. It has not been touched.

Pages are generated by `tools/build.mjs` from the content in `tools/` and `content/`. After changing content, rebuild every page from the site folder with:

```
node tools/build.mjs
```

Editing a generated `.html` file directly works, but the next rebuild overwrites it, so put lasting changes in `tools/` or `content/` (or ask Claude to).

## Adding your own photos and video

Every photo has a WebP copy next to it (same name, `.webp`), which browsers load first because it is smaller. When you replace a photo, replace its `.webp` too, or delete the old `.webp` so the new `.jpg` is used.

### Hero video

The home page hero is an 8-second looping plant-room video, made with Google Flow (Veo 3.1 Lite) following the hero video guide. Its working files (the master image, raw clips and the export) are in `..\Hanntec-Hero`, outside the site folder so they are never uploaded.

| File | What it is |
| --- | --- |
| `assets/video/hero-plantroom.webm` and `.mp4` | The video, 1280x720, silent, about 0.5 MB each |
| `assets/img/hero/hero-poster.webp` | The still shown while the video loads, and instead of it on phones |

- The video only loads on screens wider than 700 px. Phones, visitors who have reduced motion switched on, and visitors in data-saver mode see the still image.
- It pauses when scrolled out of view, and has a pause button in the bottom-right corner.
- If all three files are removed, the home page goes back to the line drawing on the next rebuild.
- To replace the video, give the new files new names, change the names in `tools/build.mjs` (search for `HERO`) and rebuild. `netlify.toml` tells browsers to keep the video for a year, so files with the same name would not refresh for returning visitors.
- The video is AI-generated. Don't present it as a real Hanntec project; the Tirlán before and after and the case studies carry the proof. Swap in real footage from a job when you have it.

## Contact form

The enquiry form on `contact.html` uses **Netlify Forms**, which is built into the hosting. It is free and unlimited on Netlify's credit plans and needs no other account.

**How it works for the visitor:**
- The form checks the fields as they go.
- It sends without leaving the page and then shows a "Thanks, we have your enquiry" panel with a copy of what they sent.
- If sending fails, everything they typed stays in the form, and they're given the phone number and email.
- With JavaScript off, the form still works: it posts to Netlify and lands on `thanks.html`.

**How it works for us:**
- Netlify checks each enquiry for spam with Akismet. Bots that fill the hidden `website` field are rejected.
- Netlify emails each enquiry to the addresses set up in Netlify. The email's subject reads like "Website enquiry: Design & engineering, Mary Byrne (Acme Foods)".
- Pressing Reply in the email replies to the customer, not to Netlify.

**One-time setup in Netlify (after this version is deployed):**

1. In app.netlify.com, open the site, go to **Forms** and select **Enable form detection**.
2. Deploy again. Push a commit, or use **Deploys > Trigger deploy > Deploy site**. Netlify only finds forms during a deploy.
3. Under **Forms**, check that a form called **enquiry** now appears.
4. Go to **Forms > Submission notifications** and add an email notification. Leave the subject blank, because the form sets its own.
   - Use the address that should receive enquiries, for example jack@hanntec.com, or a shared inbox such as enquiries@hanntec.com.
   - If the address isn't a member of the Netlify team, Netlify emails it a confirmation link. Click **Confirm** in that email, or nothing is sent.
   - Add a second address too, so an enquiry is never sitting in one person's holiday inbox.
5. Send a test enquiry from the live site. Check that:
   - it arrives within a minute or two
   - the subject line reads correctly
   - pressing Reply addresses the email to the test sender
6. If the email doesn't arrive, check the junk folder. Mark `formresponses@netlify.com` as a safe sender in Outlook (**Settings > Mail > Junk email > Safe senders**).
7. In Netlify, look under **Forms > enquiry**. Real enquiries are listed under **Verified submissions**. Anything Akismet flagged is under **Spam submissions**, where it can be marked as not spam.

**Keeping it tidy:**
- Delete old submissions in Netlify every few months, in line with the privacy notice.
- Check the spam list now and then for real enquiries that were caught.
- The form only works on Netlify. On the local preview, or any other host, it shows the "didn't send" message with the phone and email.

## Adding a project (case study)

1. Collect the facts with `content/CASE-STUDY-BRIEF.md` (it includes a permission request to send the client).
2. Add or edit the project in `content/case-studies.json`. Put its photos in `assets/img/` with a `.webp` copy of each `.jpg`.
3. Rebuild (`node tools/build.mjs`).
   - While `"draft": true`, the project has a private preview page (`case-<id>.html`) with yellow prompts for anything missing. It is not linked anywhere and search engines are told to ignore it.
   - Set `"draft": false` to publish. A Projects page and menu link appear, the home page shows the newest three projects, and the sitemap is updated. The build warns about any published project that is missing its summary, story or figures.
4. Tirlán Country Life is set up as the first draft, with its client, sector and before/after photos. Preview it at `case-tirlan-country-life.html`.

## Design notes

- The home page hero is the looping plant-room video under a navy wash, darkest behind the headline (see "Hero video"). The line drawing of a plant is the fallback if the video files are removed, and is still used in the LinkedIn banner.
- Colours come from the logo: blue `#0B3A82` and red `#C8142F` (the logo red, brightened so it reads on dark). They are the first lines of `assets/css/styles.css`.
- The header is transparent over the dark hero and turns white once you scroll. `logo-on-dark.png` (red H, lighter blue wordmark) is used over dark areas and `logo.png` (original colours) over white.
- The red rounded square on inner page headers and team portraits echoes the boxed H in the logo.
- Fonts are Barlow Condensed (headlines) and Instrument Sans (body), both open licence, stored in `assets/fonts/`, so no Google Fonts requests are made.
- The before/after slider is full width and uses two photos that each show the whole building, lined up on the fence line, with a soft blended edge and an eased divider.
- `logo.png` is the supplied logo with a transparent background. The original is only 446 px wide, so a larger file or SVG would be sharper.
